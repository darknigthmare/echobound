# ECHObound — La Cité des Échos

Édition Codex Professionnelle 2.0.0. RPG original de recrutement, d'évolution et de reconstruction d'une cité interdimensionnelle : trois partenaires de départ, douze habitants et services, quatre régions, quatre Éclats mnésiques, onze formes, boss final en deux phases, conclusions multiples et Nouveau Cycle+.

## Jouer

Ouvrir `index.html` dans un navigateur moderne, ou visiter la production Vercel. Le jeu autonome prend en charge clavier, manette et commandes tactiles.

## Vérifier

```bash
npm test
```

Le test contrôle l'intégrité du standalone récupéré, sa version 2.0.0 et les marqueurs essentiels de campagne, sauvegarde, Codex, Unisson et Nouveau Cycle+.

## Source

Cette reprise conserve octet pour octet le standalone professionnel livré par la conversation ChatGPT. Le détail vérifiable figure dans `SOURCE_PROVENANCE.md`. Les prochaines passes Codex doivent modulariser le moteur sans réécrire le postulat, supprimer du contenu ou casser les sauvegardes 1.0/2.0.
